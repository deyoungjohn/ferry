# `@ferry/core`

Shared protocol types, validation schemas, canonical CBOR hashing, timing invariants, pricing math, reveal policy, and EVM/BCH helpers used by all Ferry packages.

## Exported API

- **Order terms and canonical hashing (`terms.ts`, `signing.ts`)**: `OrderTermsSchema`, `PricingRefSchema`, `PricingEvidenceSchema`, `parseOrderTerms`, `unixTimestampSeconds`, `canonicalCBOR`, `orderId`, `signOrderId`, `verifyOrderSignature`, `assertHex32`. `unixTimestampSeconds` rejects values at or above `1e11` to prevent millisecond misuse. `canonicalCBOR` uses deterministic RFC 8949 encoding via `cborg` with byte-string encoding for hashes/categories/BCH scripts, tag-2 bignums for `uint256` amounts, and optional `PricingEvidence` signed with the terms.
- **Timing invariants (`timing.ts`)**: `invariantF`, `invariantR`, `erlangQuantile`, `DEFAULT_TIMING_CONFIG`. Pure functions taking swap deadlines, BCH tip height, `solverReactionSeconds`, `safetySeconds`, and `blockMeanSeconds`, returning a `TimingDecision` with a typed `reason`.
- **Reveal policy (`reveal.ts`)**: `revealPolicy`, `DEFAULT_REVEAL_CONFIG`. Decision function enforcing fast-lane opt-in, USD cap, BCH double-spend-proof window, and per-chain finality thresholds.
- **Pricing and peg guard (`pricing.ts`)**: `convertFloor`, `convertCeil`, `quoteExactIn`, `quoteExactOut`, `quoteOut`, `quoteInForExactOut`, `verifyPricing`, `checkLimits`, `pegGuard`, `effectiveSpreadBps`, `holdFeeBps`, `effectiveSendLinkSpreadBps`, `DEFAULT_HOLD_FEE_BPS_PER_DAY`, `MAX_SEND_LINK_WINDOW_SECONDS`. Integer-only rational arithmetic with floor rounding in the solver's favour across arbitrary token decimals (such as 6, 18, and 2), `PricingEvidence`-based quoting and Cauldron reference cross-checking, plus send-link hold fees (`10` bps/day default, up to 7 days).
- **Liquidity and reservations (`liquidity.ts`)**: `availableLiquidity`, `pruneExpiredReservations`, `reservedByAddress`, `tryReserveLiquidity`. Pure inventory-minus-exposure-minus-reservations-minus-floor math and per-address reservation ledger with expiry in Unix seconds.
- **CashAddr validation (`cashaddr.ts`)**: `decodeCashAddress`, `cashAddressToLockingBytecode`. Pure TypeScript CashAddr decoder and checksum validator supporting P2PKH, P2SH20/32, and token-aware variants.
- **Pay links (`pay-link.ts`)**: `PayLinkSchema`, `parsePayLink`, `validatePayLinkRecipient`, `isSingleUsePayLink`, `transitionPayLinkStatus`, `quotePayLinkExactOut`. Pure state machine (`open`, `reserved`, `paid`, `expired`, `cancelled`) enforcing single-use fixed-amount links vs reusable no-amount links, recipient CashAddr/bytecode matching, and exact-output quoting.
- **Send links (`send-link.ts`)**: `SendLinkSchema`, `parseSendLink`, `planSendLinkWindow`, `SEND_LINK_WINDOWS_SECONDS`. Validates send links (up to 7 days, no secret stored) and plans destination deadlines and BCH refund heights that satisfy reverse timing invariant R.
- **Link URLs (`link-url.ts`)**: `buildPayLinkPath`, `buildPayLinkUrl`, `parsePayLinkUrl`, `buildSendLinkPath`, `buildSendLinkUrl`, `parseSendLinkUrl`, `toServerRequestPath`, `redactLinkForLog`. Builds and parses `/p/<id>` and `/s/<id>#<secret>`, keeping the send-link secret exclusively in the URL fragment.
- **Balance and shortfall (`balance.ts`)**: `sumUtxoBalances`, `formatTokenUnits`, `checkBalanceShortfall`. Sums satoshi and category token balances across UTXOs and formats readable shortfall messages for arbitrary decimals.
- **Recovery (`recovery.ts`)**: `RecoveryFileSchema`, `buildRecoveryFile`, `parseRecoveryFile`, `serializeRecoveryFile`, `parseRecoveryFileJson`, `recoveryFileName`, `recoveryActions`, `buildEvmRecoveryCalldata`. Versioned recovery file schema/serializer, direction-aware user recovery planner, and EVM claim/refund calldata builder.
- **Secrets (`secret.ts`)**: `isValidSecret`, `assertValidSecret`. Enforces 32-byte preimages whose SHA-256 equals `hashLock` with no zero-secret fallback.
- **Chain configuration and adapters (`chains.ts`)**: `EvmChainConfigSchema`, `parseEvmChainConfig`, `validateEvmChainConfig`, `EVM_CHAIN_IDS`, `ChainAdapter`, and lock state/event types. Fails closed if any required token address or contract address is missing or zero.
- **EVM and BCH helpers (`evm.ts`, `category.ts`, `vectors.ts`)**: `evmLockId`, `LOCK_INTENT_TYPES`, `LOCK_INTENT_TYPEHASH`, `lockIntentTypedData`, `lockIntentDomainSeparator`, `categoryDisplayToInternal`, `categoryInternalToDisplay`, and `CROSS_CHECK_VECTORS` (also exported via `@ferry/core/vectors`).
- **API schemas and error codes (`api/index.ts`, exported via `@ferry/core/api`)**: `API_ERROR_CODES`, `API_ERROR_HTTP_STATUS`, `ApiErrorCodeSchema`, `ApiErrorResponseSchema`, `HealthResponseSchema`, `QUOTE_REFUSAL_REASONS`, `QuoteRefusalSchema`, `formatQuoteRefusalMessage`, `RouteLiquiditySchema`, `LiquidityResponseSchema`.
